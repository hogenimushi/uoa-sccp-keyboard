# uoa-sccp-keyboard

会津大学 SCCP「電子工作プロジェクト」2026年度後期の教材リポジトリです。

## この授業について

この授業では、マイコンや電子部品を使った実習や作品制作を通して、電子工作に必要な基礎的な技術を学びます。

完成した手順をそのまま実行するだけではなく、

- 分からないことを見つける
- 必要な情報を自分で調べる
- 公式ドキュメント、データシート、GitHub、AIなどを使う
- 実際のハードウェアで試す
- うまくいかなければ原因を切り分ける
- 修正して、もう一度試す

という進め方を重視します。

**作り方を教えるのではなく、作り方を自分で見つけられるようにする。**
