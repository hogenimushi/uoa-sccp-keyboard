## なぜデジタル入力を学ぶのか

前回は、XIAO RP2040から信号を出して、
LEDを点灯・点滅させました。

今回は逆に、
外からの状態をXIAO RP2040で読み取ります。

マイコンを使った装置では、

- ボタンが押された
- スイッチが切り替わった
- センサが反応した

といった外部の変化を読み取り、
その結果に応じて動作を変えます。

今回はタクトスイッチを使って、

**入力 → 判断 → 出力**

という装置の基本的な流れを作ります。

この考え方は、
USB HID、キーボード、ミニプロジェクトでも使います。

## データシートから読み取る

データシートには、

- スイッチを上から見た端子配置
- P.C.B. LAYOUT
- T1〜T4で示された回路図

があります。

これらの図を見比べて、次のことを考えてください。

- T1〜T4は、実物のどの端子に対応しているか
- 押していないとき、どの端子同士がつながっているか
- 押したとき、接続がどう変わるか

また、

**ブレッドボードにどの向きで挿せば、スイッチとして使えるか**

も考えてください。

# 3. 外付けプルアップ回路を作る

**3.3 V → 10 kΩ抵抗 → D2 → タクトスイッチ → GND**

# 4. GPIOを入力として使う

Arduinoでは、

```cpp
digitalRead()
```

を使ってGPIOの状態を読み取ります。

今回はD2を入力として使います。

```cpp
const int switchPin = D2;
```

`setup()` では、

```cpp
pinMode(switchPin, INPUT);
```

として、D2を入力に設定します。

# 6. 読み取った値をそのままLEDへ出す

まずは判断を加えず、
D2から読み取った値をそのままLEDへ出してみます。

例：

```cpp
const int switchPin = D2;
const int ledPin = D0;

void setup() {
  pinMode(switchPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int value = digitalRead(switchPin);
  digitalWrite(ledPin, value);
}
```

プログラムを書き込んだら、

- スイッチを押していないとき
- スイッチを押したとき

で、LEDがどうなるか確認してください。

## なぜそうなるのか

今回の回路では、

- スイッチを押していないとき
- スイッチを押したとき

で、D2の状態が変化します。

LEDの動作と回路を見比べながら、

**D2がHIGHのときLEDはどうなるか**  
**D2がLOWのときLEDはどうなるか**

を確認してください。

# 9. 内部プルアップを使う

先ほどは、外付けの10 kΩ抵抗を使って
D2を3.3 V側へ引っ張っていました。

XIAO RP2040では、
マイコン内部のプルアップ抵抗を使うこともできます。

外付けの10 kΩ抵抗を外したまま、

```cpp
pinMode(switchPin, INPUT);
```

を、

```cpp
pinMode(switchPin, INPUT_PULLUP);
```

に変更してください。

タクトスイッチは、
D2とGNDの間につないだままにします。

LEDの動作を確認してください。

## 3つを比較する

次の3つを比べます。

1. 外付け10 kΩプルアップを使った場合
2. プルアップを使わなかった場合
3. `INPUT_PULLUP` を使った場合

それぞれで、

- スイッチを押していないとき
- スイッチを押したとき

のLEDの状態を比較してください。

そして、

**外付けの10 kΩ抵抗で行っていたことを、`INPUT_PULLUP` ではどのように実現しているのか**

考えてください。
