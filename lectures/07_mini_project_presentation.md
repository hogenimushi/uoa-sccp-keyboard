# 第7回 ミニプロジェクト発表

## 1. 今日やること

今日は、前回までに作ったミニプロジェクトを発表します。

発表では、

- 作ったものを実際に動かして見せる
- どのように考えて作ったかを説明する
- 調べたこと、確かめたことを共有する
- 他の人の作品や工夫から学ぶ

ことを行います。

---

# 2. 発表時間

1人あたり、

- 発表：5分程度
- 質疑：2分程度

を目安とします。

発表時間には、実演も含みます。

---

# 3. 発表する内容

次の内容を説明してください。

1. **何を作ったか**
2. **どのように動くか**
3. **どの部品を使ったか**
4. **入力 → 処理 → 出力** はどのようになっているか
5. **工夫したところ**
6. 分からなかったことを **どのように調べたか**
7. 調べた内容を **どのように確かめたか**
8. うまくいかなかったこと、または改善したいこと

作品の完成度だけでなく、

**どのように考え、調べ、確かめながら作ったか**

も説明してください。

---

# 4. 実演

原則として、作ったものを実際に動かして見せてください。

動作を見せながら説明してもかまいません。

当日うまく動かなかった場合も、発表は行います。

その場合は、

- どこまでできているか
- 何がうまく動いていないか
- 何を調べたか
- どのように確認したか
- 次に何を試すか

を説明してください。

---

# 5. 発表資料

PowerPointなどの発表資料は必須ではありません。

必要に応じて、

- 回路図
- 配線の写真
- ソースコードの一部
- 動作を説明する図

などを見せてもかまいません。

実物を使って説明できるところは、実物を使って説明してください。

---

# 6. 他の人の発表を聞く

発表を聞くときは、次の点に注目してください。

- 何を入力として使っているか
- 何を出力として使っているか
- 入力をどのように処理しているか
- どのような工夫をしているか
- 自分では思いつかなかった使い方があるか
- 自分の制作にも使えそうな考え方があるか

分からないことや興味を持ったことがあれば、質問してください。

---

# 7. 発表後の振り返り

全員の発表が終わったら、次の内容を振り返ってください。

- 他の人の作品で参考になったこと
- 自分の作品で改善したいこと
- 今回の制作で分かったこと
- 今後のキーボード制作に活かせそうなこと

今回のミニプロジェクトで行った、

**考える → 調べる → 確かめる → 作る**

という流れを、次回以降の制作でも使っていきます。
