## なぜアナログ入力を学ぶのか

前回は、タクトスイッチを使ってデジタル入力を学びました。

スイッチの状態は、

- 押していない
- 押している

という2つの状態でした。

マイコンでは、このような入力を `HIGH` / `LOW` として扱うことができます。

しかし、実際の世界には2つの状態だけでは表せないものもあります。

- つまみの位置
- 明るさ

さらに、その値を使ってLEDの明るさを変えてみます。

今回の流れは、

**アナログ入力 → 数値 → PWM出力**

です。

# 3. 可変抵抗を使う

今回の入力には可変抵抗を使います。

可変抵抗には3本の端子があります。

まず、

**3本の端子がそれぞれ何をしているのか**

を調べてください。

Web検索やAIを使って構いません。

調べたら、次のように接続します。

- 一方の端子 → 3.3 V
- もう一方の端子 → GND

今回は、この電圧をXIAO RP2040で読み取ります。

# 4. サンプル1：アナログ入力を数値として見る

まず、A0の入力を読み取り、
その値をSerial Monitorに表示します。

次のプログラムを入力してください。

```cpp
const int sensorPin = A0;

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
}

void loop() {
  int value = analogRead(sensorPin);

  Serial.println(value);

  delay(100);
}
```

プログラムを書き込んだら、
Arduino IDEのSerial Monitorを開いてください。

通信速度は、

**115200 baud**

にします。

# 6. ADCとは何か

XIAO RP2040のA0に入ってくるものは、数値ではありません。

入力されるのは**電圧**です。

しかし、

```cpp
int value = analogRead(sensorPin);
```

とすると、プログラムの中では数値として扱うことができます。

電圧のようなアナログ値を数値に変換するものを、

**ADC（Analog-to-Digital Converter）**

と呼びます。

今回の流れは、

**可変抵抗の位置  
→ 電圧  
→ ADC  
→ 数値**

です。

0 Vに近いほど小さな値になり、
3.3 Vに近いほど大きな値になります。

ここで重要なのは、

**マイコンが直接「つまみの位置」を読んでいるわけではない**

ということです。

A0に入力された電圧を読んでいます。

---

# 7. PWM出力とは何か

次に、LEDの明るさを変えます。

前回までの `digitalWrite()` では、

- `HIGH`
- `LOW`

を出力しました。

そのためLEDは、

- 点灯
- 消灯

という動作をしました。

今回は、その中間の明るさを作ります。

そのためにPWMを使います。

PWMでは、出力端子を

- `HIGH`
- `LOW`

に高速で切り替えます。

その割合を変えることで、LEDの明るさを変えることができます。

例えば、

- HIGHの時間が短い → 暗い
- HIGHの時間が長い → 明るい

となります。

このHIGHになっている時間の割合を、

**デューティ比**

と呼びます。

PWMでは、自由な中間電圧をそのまま出力しているわけではないことにも注意してください。

# 9. サンプル2：アナログ入力でLEDの明るさを変える

次に、

**可変抵抗の値を使ってLEDの明るさを変えます。**

次のプログラムを入力してください。

```cpp
const int sensorPin = A0;
const int ledPin = D4;

void setup() {
  pinMode(ledPin, OUTPUT);

  analogReadResolution(12);
  analogWriteResolution(8);
}

void loop() {
  int value = analogRead(sensorPin);

  int brightness = map(value, 0, 4095, 0, 255);

  analogWrite(ledPin, brightness);
}
```

プログラムを書き込んだら、
可変抵抗をゆっくり回してください。

LEDの明るさがどのように変化するか観察します。

---

# 10. プログラムの流れを読む

このプログラムでは、

**入力 → 変換 → 出力**

の3つの処理をしています。

## 1. 入力する

```cpp
int value = analogRead(sensorPin);
```

A0に入力された電圧をADCで数値に変換します。

今回は、

**0〜4095**

の範囲の値として扱います。

## 2. 値を変換する

```cpp
int brightness = map(value, 0, 4095, 0, 255);
```

入力値を、

**0〜4095**

から、

**0〜255**

へ変換しています。

例えば、

- 入力が0 → 出力が0
- 入力が4095 → 出力が255

になるように変換します。

## 3. 出力する

```cpp
analogWrite(ledPin, brightness);
```

変換した値をPWM出力としてD4に出します。

その結果、LEDの明るさが変化します。

前回は、

**スイッチ  
→ `digitalRead()`

→ `digitalWrite()`  
→ LED ON / OFF**

でした。

今回は、

**可変抵抗  
→ `analogRead()`

使っている命令は違いますが、

**入力 → 処理 → 出力**

という基本的な構造は同じです。
