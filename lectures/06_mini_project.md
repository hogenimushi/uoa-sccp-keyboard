# 3. マイコン内蔵LEDスティック

今回使用するLEDスティックには、WS2812Bというマイコン内蔵RGB LEDが8個並んでいます。

通常のLEDとは違い、それぞれのLEDに対して、

- 赤
- 緑
- 青
- 明るさ

を個別に指定できます。

今回使うLEDスティックは、

**AE-WS2812B-STICK8**

です。

---

# 4. LEDスティックを接続する

LEDスティックの入力側を使います。

- 5V → 5V
- GND → GND
- DIN → XIAO RP2040のデジタル出力ピン

今回は、DINをD3へ接続します。

> **注意：電源と信号の電圧は異なります。**  
> LEDスティックの電源には **5V** を使います。  
> 一方、DINへ送る信号はXIAO RP2040の **3.3Vロジック** です。  
> このLEDスティックはDINの入力電圧範囲が2.7〜5.7Vなので、XIAO RP2040の3.3V信号をそのまま入力できます。

> DOUT側ではなく、DIN側へ接続してください。

# 6. 8個のLEDを順番に光らせる

次のプログラムを書き込みます。

```cpp
#include <Adafruit_NeoPixel.h>

const int ledPin = D3;
const int ledCount = 8;

Adafruit_NeoPixel pixels(ledCount, ledPin, NEO_GRB + NEO_KHZ800);

void setup() {
  pixels.begin();
  pixels.clear();
  pixels.show();
}

void loop() {
  for (int i = 0; i < ledCount; i++) {
    pixels.clear();

    pixels.setPixelColor(
      i,
      pixels.Color(0, 50, 0)
    );

    pixels.show();

    delay(200);
  }
}
```

8個のLEDが順番に光ることを確認してください。

---

# 7. プログラムを読む

```cpp
Adafruit_NeoPixel pixels(ledCount, ledPin, NEO_GRB + NEO_KHZ800);
```

で、

- LEDの個数
- 使用するGPIO
- LEDの通信方式

を設定しています。

色は、

```cpp
pixels.Color(0, 50, 0)
```

のように、赤・緑・青の値で指定します。

例えば、

```cpp
pixels.Color(50, 0, 0)
```

なら赤、

```cpp
pixels.Color(0, 0, 50)
```

なら青です。

```cpp
pixels.setPixelColor(i, ...);
```

で、どのLEDを光らせるか指定します。

8個のLEDには、

```text
0 1 2 3 4 5 6 7
```

と番号が付いています。

最後に、

```cpp
pixels.show();
```

で設定した内容をLEDへ送ります。

# 9. これまでの部品と組み合わせる

LEDスティックは、これまで使った入力と組み合わせることができます。

例えば、

- タクトスイッチを押す → LEDを赤くする
- 可変抵抗の値 → LEDの明るさを変える
- CdSの値 → 光るLEDの数を変える
- アナログスティックの位置 → 光るLEDの位置を変える
- USB HIDの入力と同時にLED表示も変える

といったことができます。

例えば、

**アナログスティック  
→ `analogRead()`  
→ LED番号へ変換  
→ WS2812B**

という流れを作れます。
